Simple Web Server

A small HTTP server written in C — now serving this page.

This site is being served by a lightweight, multi-threaded web server built from scratch with POSIX sockets. No frameworks, no dependencies — just a single C file that accepts connections and returns files.

  • Serves static files (HTML, CSS, images, plain text)
  • Handles GET and POST requests
  • One thread per request for concurrency
  • Configurable through a simple .serverConfig file
