About this project

Simple Web Server is a compact HTTP server written in C. It listens on a TCP socket, parses a request, and returns the matching file from its web root. It was written as a learning project to understand how web servers work under the hood.

Author: Pavneet Singh · github.com/pavnxet

How it works

  • Creates a socket and binds it to the port in .serverConfig.
  • Accepts each connection and spawns a thread to handle it.
  • For a GET request, resolves the file path and streams it back with the correct Content-Type.
  • For a POST request, reads the body and echoes it back.
  • Rejects path-traversal attempts (..) with a 403 response.

Run it locally

git clone https://github.com/pavnxet/simple-web-server.git
cd simple-web-server
make
./serverd

Then open http://localhost:8080.
